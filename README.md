# ⚡ FunTime Minecraft Server Launcher

Красивый и функциональный лаунчер для запуска Minecraft сервера на базе Electron + React.

## 🚀 Быстрый старт

### Требования
- Node.js (v14 или выше) — скачивай с https://nodejs.org/
- Java (для запуска Minecraft сервера)
- Windows, macOS или Linux

### Установка и запуск

1. **Клонируй репозиторий**
```bash
git clone https://github.com/superpixal0-cpu/funtime-launcher.git
cd funtime-launcher
```

2. **Установи зависимости**
```bash
npm install
```

3. **Запусти в режиме разработки**
```bash
npm start
```

Это запустит одновременно:
- React dev server (http://localhost:3000)
- Electron приложение

### Сборка готового EXE

**Для Windows:**
```bash
npm run build-win
```

**Для Linux:**
```bash
npm run build-linux
```

Готовый файл будет в папке `dist/`

Конфигурация сохраняется в `~/.funtime_launcher.json`

## 🔧 Проблемы и решения

**Java не найдена:**  
Убедись, что Java установлена и добавлена в PATH.

**Сервер не запускается:**  
- Проверь путь к серверу
- Проверь наличие server.jar в папке
- Посмотри логи консоли

## 📦 Деплой

Готовые EXE файлы размещаются в `dist/` папке после сборки.
